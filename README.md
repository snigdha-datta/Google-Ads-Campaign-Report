# Google Ads Campaign Report
A performance analysis of Google Ads campaigns to evaluate targeting efficiency and improve ROI.  
This project demonstrates digital marketing analytics, KPI measurement, and actionable recommendations for campaign optimization.

## Objectives
- Measure campaign performance using CTR, CPC, and conversion metrics.
- Identify high-performing audience segments.
- Recommend targeting adjustments to maximize ROI.

## Tools & Technologies
- Google Ads
- Excel (supporting analysis)
- Presentation tools (PowerPoint/PDF)

## Project Files
- **GoogleAdsCampaignReport.pdf**: Detailed report with analysis and recommendations.
  
## Methodology
1. **Data Collection**: Extracted campaign metrics from Google Ads dashboard.
2. **Data Analysis**: Measured CTR, CPC, and conversion rates across campaigns.
3. **Segmentation**: Compared audience groups to identify high-performing segments.
4. **Reporting**: Compiled insights into a structured report for stakeholders.

## Key Contributions
- Analyzed multiple campaigns to evaluate ad performance.
- Identified audience segments with above-average CTR and conversions.
- Recommended targeting adjustments to improve efficiency.

## Impact
- Increased CTR by **12%** after implementing recommendations.
- Boosted campaign ROI by **18%** through optimized targeting.
- Provided clear insights to guide future ad spend allocation.

## Learning Outcomes
- Strengthened skills in digital marketing analytics.
- Gained experience in KPI measurement and campaign optimization.
- Improved ability to translate marketing data into actionable strategies.
